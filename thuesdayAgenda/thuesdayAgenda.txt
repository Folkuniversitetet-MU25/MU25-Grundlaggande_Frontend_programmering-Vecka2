🎯 Lektionsmål  
Efter lektionen ska studenterna kunna:  

✅ Förklara vad CSS är och varför vi separerar HTML från CSS (separation of concerns)  
✅ Förstå CSS-syntax: selektor, egenskap, värde  
✅ Använda olika typer av selektorer: element, klass, ID och grupperade selektorer  
✅ Skapa och länka en extern CSS-fil till HTML  
✅ Använda enheter som px, %, vh/vw, rem och em

📢 PowerPoint – Talarmanus (Slides 29–49)  

🟨 Slide 29 – CSS  
🗣️ "CSS står för Cascading Style Sheets. Det styr hur vår HTML ser ut: färger, typsnitt, layout. HTML säger *vad* som finns, CSS säger *hur* det ser ut."  

--------------------------------------------------
🟨 Slide 30 – Webbplatsens tre delar  
🗣️ "En webbplats består av tre lager: HTML = innehåll, CSS = design, JavaScript = funktionalitet. Separation gör koden lättare att underhålla."  

--------------------------------------------------
🟨 Slide 31 – Cascading  
🗣️ "Cascade betyder att regler kan överlappa varandra. Den närmaste regeln vinner. Exempel: en generell färg kan sättas på body, men en specifik färg på h1 vinner."  

--------------------------------------------------
🟨 Slide 32 – Style  
🗣️ "Med CSS kan vi styra typografi, färger, bakgrunder, layout, marginaler, animationer och mycket mer."  

--------------------------------------------------
🟨 Slide 33 – User Agent Styles  
🗣️ "Varje webbläsare har en egen default-CSS, t.ex. att rubriker är stora och blå länkar är understrukna. Därför kan sidor se lite olika ut om man inte styr med egen CSS."  

--------------------------------------------------
🟨 Slide 34 – Webbläsarens inbyggda CSS  
🗣️ "Exempel: ett `<h1>` är alltid större än `<p>` om vi inte ändrar. Därför är det viktigt att förstå att webbläsaren *alltid* applicerar någon form av CSS."  

--------------------------------------------------
🟨 Slide 35 – Hur skapar jag en stilmall?  
🗣️ "Vi länkar in en extern CSS-fil i `<head>`:  
```html
<link rel='stylesheet' href='css/style.css'>

Det är standard och bästa praxis."

--------------------------------------------------
🟨 Slide 36 – CSS Syntax (översikt)
🗣️ "Syntaxen är: selektor { egenskap: värde; }. Selektorn pekar ut HTML-elementet, egenskapen är vad vi vill ändra, och värdet är inställningen."

--------------------------------------------------
🟨 Slide 37 – CSS Syntax (exempel h1)

Här väljer vi elementet h1 och ger det ett typsnitt, en storlek och en färg. Syntaxen är alltid densamma: selektor, egenskap, värde. Här blir rubriken rosa och i Arial, 18 pixlar.

--------------------------------------------------
🟨 Slide 38 – CSS Selectors (grundprincip)
🗣️ "Selektorer fungerar som markörer i DOM-trädet. Vi pekar ut vilka element vi vill styla."

--------------------------------------------------
🟨 Slide 39 – CSS Selectors (exempel h1)
🗣️ "Elementselektor: vi skriver helt enkelt elementets namn:

h1 { color: red; }
```"  

--------------------------------------------------
🟨 Slide 40 – CSS Selectors (exempel p)  
🗣️ "Vi kan lika enkelt styla alla paragrafer:  
```css
p { line-height: 1.6; }
```"  

--------------------------------------------------
🟨 Slide 41 – CSS Selectors (exempel em, li)  
🗣️ "Flera element kan väljas samtidigt med komma:  
```css
em, li { font-style: italic; color: grey; }
```"  

--------------------------------------------------
🟨 Slide 42 – CSS Selectors (exempel ul)  
🗣️ "Här ser vi ett exempel på listor. Genom att styla ul påverkar vi hela listan."  

--------------------------------------------------
🟨 Slide 43 – Selektorer är väldigt anpassningsbara  
🗣️ "Vi kan skriva mer avancerade selektorer, t.ex.:  
```css
section.articles > article:first-of-type h1 + h2
```

Det här används i mer avancerade projekt – men grunden är samma: välj ett element och styla det."

--------------------------------------------------
🟨 Slide 44 – CSS Properties
🗣️ "Det finns över 700 egenskaper – men vi jobbar mest med 50–70 vanliga: färger, text, layout, marginaler, osv. Alla har bestämda värden och enheter."

--------------------------------------------------
🟨 Slide 45 – CSS-dokumentet
🗣️ "Alla regler samlas i ett dokument, oftast style.css, och länkas in i HTML. Då blir det enkelt att hålla ordning."

--------------------------------------------------
🟨 Slide 46 – Klasser
🗣️ "Klasser används för att gruppera element. Exempel:

<h1 class='large'>Titel</h1>

.large { font-size: 30px; }
```"  

--------------------------------------------------
🟨 Slide 47 – Flera klasser  
🗣️ "Ett element kan ha flera klasser:  
```html
<button class='round small-btn'>Köp</button>

.round { border-radius: 100px; }  
.small-btn { width: 80px; height: 30px; }
```"  

--------------------------------------------------
🟨 Slide 48 – Konventioner?  
🗣️ "Använd tydliga namn på klasser. Håll regler nära varandra i CSS. Så lite HTML som möjligt. Det här blir ännu viktigare i större projekt."  

--------------------------------------------------
🟨 Slide 49 – Enheter (px, %, vh, vw, em, rem)  
🗣️ "Olika enheter används för olika syften:  
- px = exakt storlek, bra för bilder & små detaljer  
- % = relativt förälderelementet  
- rem = relativt root-fontstorleken (ofta 16px)  
- em = relativt elementets egen fontstorlek  
- vh/vw = viewport height/width, bra för responsiv layout"

💻 Code-Along – style.css  

📂 Mappstruktur:  
projekt/
├── index.html
├── css/
│ └── style.css

--------------------------------------------------
Körordning på lektionen:

Öppna index.html i Live Server → visa att sidan saknar stil.

Skapa css/style.css → lägg in link i <head> → ändra body, h1, p.

Visa klass vs ID (.highlight och #main-title).

Visa grupp-selektor: t.ex. h2, h3, p { … }.

Visa block vs inline: styla .box (block) och .chip (inline-block), låt studenterna se beteendet.

Låt dem prova enheter (px, %, rem, em, vh/vw) på t.ex. font-size och width.

--------------------------------------------------
📝 index.html (huvuddel):  

```html
<!DOCTYPE html>
<html lang="sv">
<head>
  <meta charset="UTF-8" />
  <title>CSS Intro – Blogg</title>
  <!-- Viktigt: pekar på din externa CSS -->
  <link rel="stylesheet" href="css/style.css" />
</head>
<body>
  <header>

Steg 1: Inline style (visa snabbt varför det är “fult”)

  <h1 style="color:red; font-size: 28px;">Min blogg</h1>
<p style="color:green;">Detta är ett exempel på inline-style.</p>

🗣️ Talarmanus:
"Inline-style betyder att vi lägger CSS direkt i HTML-elementet. Det fungerar – men det gör koden svår att underhålla. Om vi vill ändra färgen på alla rubriker måste vi leta upp varenda <h1> och uppdatera. Därför använder vi external CSS i stället."


    <!-- ID för att visa skillnaden mellan #id och .klass -->
    <h1 id="main-title">Min blogg</h1>
    <nav>
      <!-- Inline-element (a) bra för att visa skillnaden mot block -->
      <a href="#">Hem</a> |
      <a href="#">Artiklar</a> |
      <a href="#">Om mig</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Första inlägget</h2>
      <p>
        Välkommen till min blogg! Här testar vi lite grundläggande CSS.
        Lägg märke till hur <span class="highlight">den här frasen</span>
        kan få en annan färg med en klass.
      </p>

      <figure>
        <!-- Lägg en testbild i /img/artikelbild.jpg eller byt src -->
        <img src="img/artikelbild.jpg" alt="En bild som hör till artikeln" />
        <figcaption>En bildtext under bilden</figcaption>
      </figure>

      <h3>En punktlista</h3>
      <ul>
        <li>Rubriker: <code>h1, h2, h3…</code></li>
        <li>Brödtext: <code>p</code></li>
        <li>Länkar: <code>a</code></li>
      </ul>

      <h3>Grupp-selektor-demo</h3>
      <p class="note">
        Den här paragrafen har klassen <code>.note</code> (bra att
        demonstrera klass-selektor). Prova också gruppera:
        <code>h2, h3, p { … }</code>
      </p>
    </article>

    <aside>
      <h4>Sidoinformation</h4>
      <p>Här kan vi lägga små notiser eller länkar.</p>
      <ul>
        <li><a href="#">Ny artikel</a></li>
        <li><a href="#">Om författaren</a></li>
      </ul>
    </aside>

    <!-- Block vs Inline demo -->
    <section>
      <h3>Block vs Inline</h3>
      <div class="box">Jag är ett block-element (div) – bryter rad och tar hela bredden.</div>
      <div class="box">Ännu ett block.</div>
      <p>
        Här är inline-element:
        <span class="chip">chip 1</span>
        <span class="chip">chip 2</span>
        <a class="chip" href="#">chip-länk</a>
        – de ligger kvar på samma rad (tills de tar slut).
      </p>
    </section>
  </main>

  <footer>
    <p>© 2025 Min blogg – Kontakt: <a href="mailto:info@example.com">info@example.com</a></p>
  </footer>
</body>
</html>

📝 style.css:

/* Bas */
body {
  background-color: #f4f4f4;  /* ändra i code-alongen */
  font-family: system-ui, Arial, sans-serif;
  line-height: 1.6;
  margin: 0;
  padding: 0 16px;
}

/* Element-selektorer */
h1 {
  color: #0b3d91;             /* ändra i code-alongen */
  margin: 16px 0 8px;
}

p {
  font-size: 18px;            /* ändra i code-alongen */
}

/* Klass & ID */
.highlight { color: crimson; }
#main-title { text-transform: uppercase; letter-spacing: 1px; }

/* Layout/struktur (bara lite, så ni ser skillnad) */
header { padding: 16px 0; }
nav a { text-decoration: none; margin-right: 8px; }

main {
  display: block;             /* semantiskt element – visas som block by default */
  max-width: 900px;
  margin: 0 auto;
  padding-bottom: 24px;
}

article { margin: 16px 0; }
aside {
  background: #fff;
  border: 1px solid #ddd;
  padding: 12px;
  margin: 16px 0;
}

/* Block vs inline demo */
.box {
  background: #e8eefc;
  border: 1px solid #c2d3ff;
  padding: 8px;
  margin-bottom: 8px;
}

.chip {
  display: inline-block;     /* visa att den fortfarande håller sig “inline” i flödet */
  padding: 2px 8px;
  border: 1px solid #bbb;
  border-radius: 999px;
  text-decoration: none;
  margin-right: 6px;
  font-size: 14px;           /* testa px → rem/em/vw i genomgången */
}

/* Liten visuell hjälp för figure */
figure { margin: 16px 0; }
figcaption { font-size: 0.9rem; color: #555; }

/* Exempel-klass för paragrafen med .note */
.note {
  background: #fffbe6;
  border-left: 4px solid #ffd666;
  padding: 8px 12px;
}



🗣️ Talarmanus:
"Nu ser vi hur sidan förändras när vi lägger till CSS. Body får bakgrundsfärg, h1 får annan textfärg, p får större fontstorlek, och klassen .highlight kan användas för att markera delar av texten."
